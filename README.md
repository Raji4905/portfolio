## Design Direction
Premium, clean, minimal, portfolio for **technical/software job placements** — not a flashy creative-agency site. Think: confident whitespace, strong type hierarchy, restrained accent color, subtle motion (not gimmicky).

- **Typography**: one modern sans-serif for headings (e.g. Inter, Sora, or Space Grotesk) with clear weight contrast; keep body text highly readable at 16–18px.
- **Color**: neutral base (near-black / near-white) with a single accent color (e.g. electric blue or teal) used sparingly for CTAs, links, and highlights. Dark mode = deep charcoal background, not pure black. Light mode = soft off-white, not pure white.
- **Layout**: generous section padding, 1200px max content width, card-based project and skill sections with soft shadows/borders (no harsh drop shadows), rounded corners (8–12px).
- **Motion**: fade/slide-in on scroll for sections, smooth hover states (scale/border/shadow shift) on cards and buttons — subtle, no bouncing or excessive parallax.
- **Icons**: use a clean icon set (e.g. lucide-react or simple-icons) for skills, socials, and contact — not emoji.
- **Avoid**: neon colors, glassmorphism overload, stock testimonial blocks, fake stats/counters.
